## Problem

Two layers, both from the issue body, both re-verified:

1. **Today:** `const LICENSE_UPDATE_ENDPOINT: &str = "";` (`lib.rs:178`) is a **second** const that must flip at v1.0, in a second language, with nothing linking it to `LICENSE_GATE_ENABLED` in `tsup.config.ts:20`. `entitled_license_id` (`lib.rs:2321-2336`) opens with `if LICENSE_UPDATE_ENDPOINT.is_empty() { return None; }`, and `build_updater`'s `None` arm (`:2342-2357`) is `app.updater()` — the **public** manifest from `tauri.conf.json:107-109`. Flip the tsup const alone and the run gate arms while the update window stays inert.
2. **After the flip:** `entitled_license_id` also returns `None` for "gate active, window expired" — and that `None` lands on the same public manifest. A customer whose year is up is offered exactly the builds everyone else gets, so the update window still gates nobody. The const is necessary and not sufficient.

`docs/security.md:181` and `docs/licensing-explained.md:15-24, :448-453` already describe (1) accurately after #1821's sweep; their line citations (`:171`, `:2298`, `:2317-2332`) have drifted and their "neutralising the public endpoint is part of the flip" sentence stops being true once (2) is fixed here.

## Fix

**Rust — make the route a three-way, not a two-way (`src-tauri/src/lib.rs`).** The issue names the choice: *"the `tauri.conf.json` endpoint has to be neutralised, **or** the `None` arm has to mean 'no updates'."* Take the second, because it is the one that cannot be forgotten at flip time.

```rust
/// Which manifest an update check may use. Three outcomes, not two: today's
/// `Option<String>` collapsed "no Worker configured" and "configured, but this
/// device is not entitled" onto one `None`, and that `None` is the PUBLIC
/// manifest (#1785).
enum UpdateRoute {
    /// No Worker endpoint compiled in — pre-v1.0. The public manifest from
    /// `tauri.conf.json`, byte-identical to shipped behaviour.
    Public,
    /// Entitled: the license Worker, with the opaque `X-Tandem-License-Id`.
    Licensed(String),
    /// An endpoint IS compiled in and this device is not entitled, or the
    /// loopback probe could not answer. Serve NO manifest — never the public one.
    /// The `&'static str` is a log reason; #1786 (H-b) promotes it to user copy.
    Withheld(&'static str),
}
```

- **`fn update_route(endpoint: &str, status: Option<&LicenseStatusResponse>) -> UpdateRoute`** — pure, `#[cfg(test)]`-reachable, no `AppHandle`. `endpoint.is_empty()` ⇒ `Public`. `status: None` (probe failed / non-200 / undeserializable) ⇒ `Withheld("status-unavailable")` — **fail closed**: this is the product's only revenue control, and the sidecar being unreachable means Tandem is barely running anyway. `gate_active && update_window_current && license_id.is_some()` ⇒ `Licensed(id)`. Everything else (gate dark, trial, restricted, expired window, scrubbed body) ⇒ `Withheld("not-entitled")`.
- **`entitled_license_id` becomes `async fn resolve_update_route(app) -> UpdateRoute`** — same body, same total-failure discipline (it still never errors), but it keeps the endpoint check first so that **while the const is empty it returns `Public` without making the loopback probe at all**, exactly as today. That early return is the byte-identity argument for this whole change; do not "tidy" it below the probe.
- **`build_updater` returns `Result<Option<Updater>, String>`.** `Public` ⇒ `Ok(Some(app.updater()?))` (unchanged). `Licensed(lid)` ⇒ `Ok(Some(…endpoints(vec![endpoint])…header(…)…))` (unchanged). `Withheld(reason)` ⇒ `log::info!` naming the reason and `Ok(None)`. **Consequence worth stating in the PR body: after the flip the public manifest becomes unreachable by construction**, so `tauri.conf.json`'s endpoint stops being a live hole and its removal drops from "must not forget" to "verify".
- **Both callers.** `check_for_update` (`:2359-2362`): `Ok(Some(u)) => u`, `Err(e) =>` the existing dialog, and a new `Ok(None) =>` arm that logs and, when `manual`, shows a dialog. `install_update` (`:2430-2433`): `Ok(None)` ⇒ `Err("No updates are available for this installation.")`. **Do not route `Ok(None)` into `show_up_to_date_dialog`** — "You're running the latest version" is the exact lie #1786 exists to detect.
- **The manual-check dialog** is one small `show_updates_withheld_dialog(app, reason)` with honest placeholder copy naming the update window. **#1819 (H-c) owns the final wording and the ended-window branch of the up-to-date dialog** — this PR creates the branch it will write into, and says so in a comment. All of it is unreachable while the const is empty.
- `Url` parsing stays inside the `Licensed` arm, so a malformed configured endpoint is still `Err`, not a silent fall-through to public.

## Tests

`update_route` cases, each killing a specific wrong implementation:

- empty endpoint + `None` status ⇒ `Public` — kills a fix that makes a *dark* build stop checking for updates. This is the shipped path and the byte-identity guarantee.
- empty endpoint + an entitled status ⇒ `Public` — the endpoint check must stay first; kills a reordering that starts probing loopback on every dark build.
- configured + `gate_active`, `update_window_current`, `license_id: Some` ⇒ `Licensed("…")`.
- configured + `update_window_current: false` ⇒ `Withheld` — **the case the issue names**, and the one that is `app.updater()` today.
- configured + `gate_active: false` ⇒ `Withheld`; configured + `license_id: None` with both flags true ⇒ `Withheld` — kills an `unwrap_or_default()` that would send an empty header.
- configured + `status: None` ⇒ `Withheld("status-unavailable")` — pins fail-closed, so a later "be forgiving when the sidecar is slow" edit is a visible diff.

The consts test: on current source, gate `false` and endpoint `""` ⇒ green. Mutation-check both directions by hand (flip each literal in the worktree, watch it go red, restore **from a copy, never `git checkout`**) and record it in the PR body — a pin that has never been seen red is not a pin.
