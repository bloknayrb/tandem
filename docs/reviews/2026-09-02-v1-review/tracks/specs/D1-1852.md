## Problem

The report's shape is confirmed exactly. `loadMarkdown` → `saveMarkdown` over `docs/reviews/2026-09-02-v1-review/README.md` as it stands on master:

```
DIFF docs/reviews/2026-09-02-v1-review/README.md  lines(src=63 out=63) differing=1 idempotent=true
  line 29:  - "|---|---|"
            + "| - | - |"
```

Exactly one differing line, the table delimiter row — the hunk the reporter remembered before the evidence was lost. The second save is a fixed point.

**Root cause is the already-known one, not a new defect.** `markdown.ts`'s `remarkGfm({ tablePipeAlign: false })` comment says it: "It does NOT reproduce hand-authored `|---|---|` geometry, and no option can — mdast carries no source markers — so compact delimiter rows still change once, and only once." The corpus already registers `tests/fixtures/roundtrip/table-compact.md` with `blockedOn: "table geometry"` (`roundtrip-corpus.test.ts:40-43`). **This README is that fixture in the wild.** The issue's own ask allows for exactly this outcome: "either be shown to be the same root cause or get its own fixture" — it is shown, so no new fixture.

**The "unedited" half of the title is refuted, and the refutation is the interesting half.** `autoSaveAllToDisk` (`src/server/mcp/document-service.ts:1124-1140`) skips any document that is not dirty — `if (!isDirty(docId)) continue;`, the #851/#605 fix whose comment reads "Merely opening a file to view it must not round-trip it through the serializer + rewrite it on disk." Autosave of an *unedited* document cannot write at all, so the observed write means the document was **dirty**. `documents/dirty.ts` bumps the version on ANY body-fragment change regardless of origin — deliberately, so Claude's `mcp` writes persist — which means a normalization applied by the browser's Tiptap schema on first sync marks a document dirty with no human edit. Settling *which* normalization did it needs a live client and is not decidable from the server.

## Fix

**No code change, and no new test.** Reproducing hand-authored delimiter geometry needs a per-node source-marker layer that #1448 already scoped out; inventing one here is the calibration mechanism this sweep parks groups for. What lands is the record the issue asks for:

`tests/server/file-io/roundtrip-corpus.test.ts` — the `table-compact.md` entry's `why` string names this issue alongside the mechanism, so the next reader of the allowlist finds the real-world instance instead of re-deriving it:

```ts
"table-compact.md": {
  blockedOn: "table geometry",
  why: "hand-authored |---|---| cannot be reproduced; mdast carries no source markers (#1448, observed in the wild on a repo doc in #1852)",
},
```

That registration is already the guard that matters: it asserts the fixture is **still** broken, so a future memorizing fix makes it fail and forces the entry to be removed deliberately rather than silently.

Rules that bite: no source change, no Y.Doc write, no MCP surface — `docs/mcp-tools.md` needs no Errors edit.
