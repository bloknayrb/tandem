## Problem

`skills/tandem/SKILL.md:159`'s not-running message tells Claude to tell the **user**: "Start the Tauri app or run `tandem start`". Tauri is the framework; the product name everywhere user-facing (README, user guide, CHANGELOG) is "the desktop app".

**The same sentence also ships from `src/`, and that is where users actually hit it.** Three user-instructional copies survive: `src/cli/mcp-stdio.ts:1413` and `:1430` (the synthesized `-32000` connect-failure messages an MCP client shows when the server is not running — literally the text in front of a user whose `/mcp` just failed) and `src/cli/preflight.ts:68`. They are in scope for this PR under the two-person "fix it rather than file it" rule; see Fix step 6. `docs/troubleshooting.md` is **not** a survivor of any kind — it contains no "Tauri app" string at all (its sole "Tauri" mention, at `:162`, is developer-facing explanation and stays). The remaining `src/` matches for "Tauri" are `Tauri app-data dir` in `src/server/platform.ts:39`, `src/server/mcp/routes/license.ts:170` and `SettingsLicenseTab.svelte:136` — a directory name, not instructional copy, and untouched.

(The "or rewrites" half is `W13a-1991.md`'s round-1 correction and must match the wording used on the schema and in `docs/mcp-tools.md`.) The following sentence about a background tab (#1997) stays verbatim.
3. Frontmatter `version: 25` → **`26`** (re-check `origin/master` at implementation time and use the next integer above whatever it carries — the sweep has had two groups move this number).
