**Two E2E, one new file `tests/e2e/inbox-pull-path.spec.ts`**, modelled on
`annotation-lifecycle.spec.ts` (same `McpTestClient` + `createFixtureDir` / `cleanupAllOpenDocuments`

cross-process step is `expect.poll`ed**: `submitAnnotation` returns on the click

  22 without — so a literal reds on any jq-less machine and blocks pushes there, and that the pin
