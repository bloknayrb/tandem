# G7 — #1738 the Markdown source view cannot wrap long lines

Branch `fix/editor-quick-controls-text-size-and-reading-measure-outside-settings-and-source-view-line-wrap-1705`. Closes #1738.

Sweep wave 9 group G7. Not a v1-review ledger row. Independent of the display menu. Anchors hold on `origin/master` `5b1454d2`.

## Problem

`.source-view-textarea` in `src/client/editor/SourceView.svelte` sets `white-space: pre` (`:400`) and `overflow: auto` (`:401`). Any Markdown paragraph wider than the pane therefore scrolls sideways. There is no setting to change this.

## Fix

**`src/client/hooks/useTandemSettings.ts`**, following `showRawMarkdown` (`:177`, `:284`, `:626`):
- Add `sourceViewLineWrap: boolean`.
- Default it to `false`.
- Normalize it in `normalizeKnownFields` as `parsed.sourceViewLineWrap === true`.

**No schema bump.** This follows `showRawMarkdown` exactly: `use-tandem-settings-migration.test.ts:68-70` records that field as a pure read with no version bump. `CURRENT_SCHEMA_VERSION` stays `20`.

**Default off.** It keeps every existing user's source view unchanged, and the issue asks for an *option*. Flipping it later is a one-line change, recorded as an assumption.

**`src/client/components/EditorSettings.svelte`.**
- Add a checkbox block after the raw-markdown block, copying its markup, including `disabled={readOnly}`.
- `data-testid="editor-source-line-wrap"`.
- Label "Wrap long lines in Markdown source".
- The issue says "Appearance section", but the `showRawMarkdown` toggle it names as the precedent lives in EditorSettings. This one goes next to it.

**`src/client/editor/SourceView.svelte`.**
- Add a `lineWrap?: boolean` prop (default `false`), with `class:wrap={lineWrap}` on the textarea.
- Add a scoped `.source-view-textarea.wrap { white-space: pre-wrap; overflow-wrap: anywhere; }`.
- `overflow-wrap: anywhere` is needed: `pre-wrap` alone does not break a long unbroken URL.
- Standard properties only; component CSS goes through lightningcss.

**`src/client/App.svelte`.** At `<SourceView>` (`:2975`), pass `lineWrap={settingsState.settings.sourceViewLineWrap}`.

**Testid and docs.**
- `editor-source-line-wrap` is additive. Regenerate the snapshot.
- Add a manifest entry next to `appearance-show-raw-markdown`.
- Add "source-view line wrap" to the Editor row in `docs/user-guide.md:351`.

**Not added to the display menu.** The issue requires only Settings, and the menu's presets are about the formatted editor.
