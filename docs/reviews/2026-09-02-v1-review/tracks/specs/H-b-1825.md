## Problem

2. **`revoke()`'s re-check is two adjacent KV reads (narrows nothing); no wiring test pins `X-Tandem-License-Id` across `lib.rs:2241` / `worker.ts:64`.** Two claims:
   - *"narrows nothing"* is **approximately right and literally wrong.** The two `readOrder` calls in `revoke()` (`:456` and `:467`) are adjacent, but the tombstone write follows the second, so the exposed window is the second read's snapshot-to-write rather than the first's — one KV round trip narrower, not zero. What it is not is `issue()`'s narrowing, which spans the async Ed25519 sign and is the case the shared comment describes. The defect is the comment, not the read.
   - The header-literal claim is **confirmed**: `src-tauri/src/lib.rs:2350` writes `.header("X-Tandem-License-Id", lid)` and `infra/license-update-worker/src/worker.ts:64` declares `export const LICENSE_HEADER = "X-Tandem-License-Id"`, in two languages, in two build graphs, with nothing comparing them. If they drift, every licensed update check silently becomes `no-header` — the exact "You're up to date forever" state #1786 exists to detect, arriving through a rename rather than a KV loss.

## Fix

Bullets 1 and 2 are implemented as part of the #1793 change; see `H-b-1793.md` for the file-and-symbol detail. Restated here only so the #1825 mapping is auditable:

- **Bullet 1** → `isAlertable` gains `config`, `config-support-email` and the new `config-resend-from`, enumerated; `alertBody` gains its third arm; `resendIsSuspect` widens so the alert about a broken `RESEND_FROM` is not sent *from* that address. (`H-b-1793.md` § Fix.)
- **Bullet 2, first half** → keep the second `readOrder`, rewrite its comment to state what it actually narrows (one KV round trip, not the request). Deleting the read to fix a comment would remove a real if small narrowing.
- **Bullet 2, second half** → **new file `tests/docs/license-header-parity.test.ts`**, in the established `tests/docs/*-claims` pattern and using the existing helper `tests/docs/rust-sources.ts` (already on master — `rustSourceDefining(pattern, what)`, which matches `.code` with comments and `#[cfg(test)]` modules stripped, and fails loudly on zero *or* two matches). The test:
  - resolves the one Rust source defining the updater's header write via `rustSourceDefining(/\.header\(\s*"X-Tandem-License-Id"/, …)`, extracts the literal from `.code` — **never `.text`**, for the reason that helper's docblock records: a commented-out or `#[cfg(test)]` copy is matched first by a `.text` scan and the guard then reports a pass while the live literal has drifted;
  - reads `LICENSE_HEADER` out of `infra/license-update-worker/src/worker.ts` by import, not by regex — it is a real export, so import it;
  - asserts the two are equal, **case-sensitively as written** (HTTP header names are case-insensitive on the wire, so this pins the source convention rather than a protocol requirement — say that in the comment, or the next reader will "fix" it to `toLowerCase()` and delete the drift signal);
  - carries a **positive control**: assert the Rust file the helper resolved is `src-tauri/src/lib.rs`, so a walk that silently matched nothing cannot satisfy the assertion. `rust-sources.ts`'s own docblock requires this of every caller.
  - `tests/docs/**` is in `tsconfig.tests.node.json` and runs in the required `check` job, so no further wiring is needed — this is a two-assert parity test, not a scanner.
- **Bullet 3** → no code. Add nothing: `docs/licensing-operations.md` §8 already carries the line ("…and that the Worker's Ed25519 import works on real Cloudflare — it never has, and a key-import failure fails closed to 503 on *every* webhook"). Listed for Bryan.

## Tests

`tests/docs/license-header-parity.test.ts`, three assertions, all discriminating:

1. **The literals match.** Kills a rename on either side. Mutation-check by hand both ways (edit the Rust literal to `X-Tandem-Licence-Id`; edit `LICENSE_HEADER`) and restore **from a file copy, never `git checkout`** — a pin never seen red is not a pin.
2. **The resolved Rust file is `src-tauri/src/lib.rs`.** The positive control: without it, a helper that matched zero files would throw, but a future refactor that moves the write into a new module and leaves a stale duplicate would resolve ambiguously and the failure would read as a missing file rather than a drift.
3. **The extraction reads `.code`.** Paste a commented-out `.header("X-Tandem-Licence-Id", lid)` above the live line and confirm the test stays **green** — a red here means the extraction is reading `text`, which is the defeat the helper exists to close.
