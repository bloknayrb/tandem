**Nothing here flips.** `LICENSE_GATE_ENABLED` stays `false` in `tsup.config.ts`. Byte-identical while dark is a constraint on this PR, not something it relaxes. ## Problem

1. **`firstRunAt: ""` is a perpetual 14-day trial** — a real fail-open. `license-state.ts:129` reads `tf?.firstRunAt ? new Date(tf.firstRunAt).getTime() : nowMs`, so `""`, `null`, `0` and a missing key all take the *absent-file* branch on **every dispatch**, and `ensureTrialStarted` never rewrites the file (bare `fs.existsSync` early return at `:183`, `flag: "wx"` at `:191`). A non-empty *unparseable* value fails the opposite way (NaN ⇒ restricted). Two directions for one file; decision 5 says the empty string is treated like the unparseable one.
   **The hand-edited `firstRunAt` is not the likeliest route in.** `readJson` swallows every parse failure into `null` (`:42-48`), so a zero-byte or truncated `trial.json` — the ordinary artefact of a crashed or disk-full write — takes the same absent-file branch and yields the same unbounded trial, and `ensureTrialStarted` can never repair it because its guard is existence, not validity. Closing only the exotic shape while `Closes #1788` reads as closing the class is what the fix below avoids: it takes both, in the two places that own them.
2. **Restricted mode is asymmetric.** `tandem_resolveAnnotation` (`annotations.ts:525`) is on `withErrorBoundary`, so Claude can accept/dismiss while restricted; the human cannot, because accept/dismiss is a write to the document room's `Y.Map('annotations')` and Surface A marks document rooms read-only (`connection-gate.ts:17`). Decision F: restricted is symmetric read-only.
3. **The armed suite never exercises restricted.** `TANDEM_LICENSE_GATE=1 npx vitest run` is 10,140 green because no `trial.json` means a *fresh* trial, and every unit test injects `gateEnabled`/`LicenseState` itself. That is why (1) and (2) could both be true and nothing was red. This is the load-bearing deliverable; treat (1) and (2) as things it should have caught.

## Fix

- **`src/server/license/license-state.ts` — one predicate, two callers, and neither may soften without the other.**
  Add a module-private predicate beside `readJson`:
  ```ts
  /** A parsed trial.json whose `firstRunAt` can actually run a clock. */
  function hasUsableFirstRunAt(tf: unknown): tf is TrialFile {
    if (typeof tf !== "object" || tf === null) return false;
    const v = (tf as TrialFile).firstRunAt;
    return typeof v === "string" && Number.isFinite(Date.parse(v));
  }
  ```
  `Date.parse` rather than `new Date(x).getTime()`, because the coercions are the trap: `new Date("")` and `new Date(undefined)` ⇒ `NaN`, but `new Date(null)` and `new Date(0)` ⇒ **`0`**, a *finite* epoch that reads as a usable timestamp. Typing the field first is what makes `null` and `0` fail here rather than silently pinning the trial to 1970.
  - **`:128-129` (the dispatch path) branches on the parsed body, not on `firstRunAt`'s truthiness:**
    ```ts
    const tf = readJson<TrialFile>(trialFilePath(appDataDir));
    // A trial.json that PARSES to a non-null body is authoritative even when its
    // firstRunAt is unusable: "", null, 0 and a missing key all resolve to NaN
    // here, and NaN makes `nowMs < expiresAt` false ⇒ restricted (decision 5).
    // Only an absent — or wholly unreadable — file is day 0, which is what keeps
    // ensureTrialStarted's soft clock (ADR-040 §3) intact.
    const firstRunAt = hasUsableFirstRunAt(tf) ? Date.parse(tf.firstRunAt) : tf === null ? nowMs : NaN;
    ```
    Note precisely what `tf === null` covers and what it does not: an absent file, an unreadable one, unparseable JSON, **and** a body that is the literal `null` — `readJson` cannot separate them without a `stat` or an error channel, and does not try. A body that parses to any other scalar (`0`, `""`, `false`) is *not* null, so it reaches `NaN` ⇒ restricted. `license-state.test.ts` records both halves so the boundary is stated rather than implied.
  - **`ensureTrialStarted` (`:176-198`) stops guarding on existence and repairs instead — but it must never repair a file it could not read.** The bare `fs.existsSync` early return is what makes a corrupt file permanent in either direction — unbounded trial before this PR, unescapable restriction after it, with `RESTRICTED_MESSAGE` (`license-gate.ts:29-32`) offering only a purchase URL and no self-service recovery.
    **Do not reach for the shared `readJson` here.** It is `try { JSON.parse(fs.readFileSync(...)) } catch { return null }` (`:42-48`), which folds *"the bytes say `{version:1}`"* and *"the open threw `EBUSY`"* into the same `null` — routine on Windows under an indexer or AV. Today's `fs.existsSync` guard never opens the file, so a transient read error **cannot** touch the clock; a `hasUsableFirstRunAt(readJson(...))` guard would silently rewrite `firstRunAt` to `now` on that same error, granting a fresh 14 days on the product's only revenue control. That is a new fail-open in the same direction as the one being fixed, and none of the read-successfully cases below can go red on it.
    So read once, in this function, and discriminate the errno:
    ```ts
    let raw: string | null = null;
    try {
      raw = fs.readFileSync(filePath, "utf-8");
    } catch (e) {
      // ENOENT is the first-boot create below. Anything else — EBUSY, EPERM,
      // EACCES, EMFILE — means we do not KNOW what the file holds, and a file
      // we could not read is never repaired: rewriting it would reset a real
      // 14-day clock on a transient AV/indexer lock.
      if ((e as NodeJS.ErrnoException).code !== "ENOENT") return;
    }
    ```
    Then: `raw === null` ⇒ the **create** branch, still `fs.writeFileSync(filePath, …, { flag: "wx" })` so the concurrent stdio+HTTP first boot resolves first-writer-wins. `raw` present and `hasUsableFirstRunAt(parse(raw))` ⇒ return, byte-identical. `raw` present and unusable — bad JSON, or a body with no usable `firstRunAt` — ⇒ the **repair** branch, a **plain write** of `{version:1, firstRunAt: new Date(now()).toISOString()}` (`wx` would refuse the very file it is repairing). Parse `raw` inside its own try/catch so unparseable bytes fall to repair rather than throwing. The repair branch is last-writer-wins, and both racing writers write approximately the same `now`, so the race is benign. Same total `catch` around the writes as today.
    This is deliberately **not** a hole: the trial clock is soft by design (ADR-040 §3), and a tamperer can already delete `trial.json` for a fresh 14 days. Repair is no weaker than that and strictly kinder to a disk glitch. The three rules together are the contract, and each is load-bearing without the others: **within a run, a present-but-unusable file is restricted; at the next boot, bytes we read and could not use are repaired to a well-formed clock; bytes we could not read at all are left exactly as they are.**
    **"At the next boot" means the SERVER's boot, and that carve-out belongs in the PR body.** `ensureTrialStarted` has exactly one caller, `src/server/index.ts:385`. The two CLI paths that force `gateEnabled: true` — `runLicenseStatus` (`src/cli/license.ts:107-113`) and `runActivate` — resolve state without ever calling it, so on an armed build holding a corrupt `trial.json`, `tandem license` prints `restricted` on every invocation until Tandem is next started, even though the repair exists. That is the new asymmetry this fix introduces; the paragraph at the head of this spec notes the pathological-file case against *today's* behaviour and must name this too.

Use a realistic `now` (e.g. `Date.UTC(2026,0,1)`), **not** the file's `now: () => 0` idiom — at epoch 0 a `firstRunAt` of `null` coerces to `0` and would read as a live trial, which would make the `null` case pass for the wrong reason.
- A whole-body scalar `trial.json` (`0`) ⇒ `restricted`, and a whole-body `null` ⇒ day-0 trial. Two cases, because they are the boundary of what `readJson` can see: everything that parses to a non-null body is authoritative, and the literal `null` is indistinguishable from an absent file. Recording it is what stops the next reader assuming the file-existence claim is stronger than it is.
- **`ensureTrialStarted` repair, five cases:**
  1. an absent file writes with `wx`;
  2. a `{"version":1}` file (parses, no usable `firstRunAt`) is **rewritten** with a fresh ISO `firstRunAt` — the case that removes the new lockout;
  3. a valid file is left byte-identical — what stops the repair resetting a real trial clock on every boot;
  4. **a read that THROWS leaves the file byte-identical.** Stub `fs.readFileSync` to throw an `EBUSY` `ErrnoException` over a *valid* `trial.json`, call `ensureTrialStarted`, assert the bytes are unchanged. This is the only case that can go red on the new fail-open the errno discrimination exists to prevent: cases 1–3 all read successfully, so a `readJson`-based guard passes every one of them while silently granting a fresh 14 days on an AV lock. Add an `ENOENT`-throwing twin if it is cheap — it must take the create branch, not the return branch.
  5. **the two halves compose.** On a `{"version":1,"firstRunAt":""}` fixture: `await ensureTrialStarted(dir, now, true)` **then** `resolveLicenseState({appDataDir: dir, now, gateEnabled: true})` ⇒ `status: "trial"` with a full window. Nothing else composes them — `:74-75` cover `resolveLicenseState` alone and cases 1–4 cover `ensureTrialStarted` alone — yet production runs them in exactly that order (`src/server/index.ts:382-385`, then `resolveLiveLicenseState()` per dispatch), so without this case the Done-when's "repaired at next boot rather than an unescapable restriction" is asserted by nothing, and the armed end-to-end case at the top of this section asserts a `restricted` state the booted product never actually presents. This is also the case a later tidy of the boot order would break.

**`tests/server/license-gate-coverage.test.ts`, one new `it`** — the counts in `docs/licensing-explained.md` are the one part of the doc sweep nothing pins (`tests/docs/ai-surface-inventory-claims.test.ts:238-258` asserts row *names* only), and this PR makes `TOOL_GATES` an importable binding for the first time, which is what makes the check free. Parse the `**MCP** —` list out of `docs/licensing-explained.md`, assert it equals `GATED` as a set, and assert the surface-1 row's two numbers equal `GATED.length` and `UNGATED.length - 1` (the `-1` being `tandem_open`, the conditional in-handler). **Fail closed if either passage is not found** — a regex that silently matches nothing makes both assertions vacuous.
