# Using Tandem

Everything about writing and reviewing documents in Tandem, from install to keyboard shortcuts.
Back to the [docs hub](../README.md).

## Getting started

- [README](../../README.md) answers "what is Tandem and how do I install it?" Its
  [Install](../../README.md#install) and
  [How you work with Tandem](../../README.md#how-you-work-with-tandem) sections are the quickest
  start. Read it first.
- [The welcome document](../../sample/welcome.md) is the sample Tandem opens on first run, with the
  onboarding tutorial anchored to it. Its [tutorial](../workflows.md#onboarding-tutorial-first-run)
  is described in Workflows.
- [User guide → First launch](../user-guide.md#first-launch) covers what you see the first time.

## The editor, day to day

- [User guide](../user-guide.md) is the complete manual. Jump straight to

  [annotations](../user-guide.md#annotations), [reviewing annotations](../user-guide.md#reviewing-annotations),
  [chat](../user-guide.md#chat), [settings](../user-guide.md#settings) and
  [keyboard shortcuts](../user-guide.md#keyboard-shortcuts).
- [Saving](../user-guide.md#saving) and

  file actually change?"
- [Supported formats](../user-guide.md#supported-formats) lists what opens and what is read-only.

- [Solo / Tandem mode](../user-guide.md#solo--tandem-mode) explains what the title-bar toggle holds
  back from the AI.
