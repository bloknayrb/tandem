# History

> **Historical: these sets record what was true, planned or believed on the date each file was
> written. They are not current guidance.** For how Tandem works now, use the other maps; for
> what is ahead, the [roadmap](../roadmap.md); for what shipped, the [CHANGELOG](../../CHANGELOG.md).
> These files are indexed, not updated, and a link or claim inside one may have gone stale.

Dated plans, reviews, evidence and design records, one row per set. Back to the
[docs hub](../README.md).

| Set | What it holds |
|---|---|
| [Plans](../plans/README.md) | Implementation plans and design reviews written before a change, mostly August and September 2026; [archived plans](../plans/README.md#archived) holds the earlier ones (Tauri, Cowork detection, the design-system stages, release plans). |
| [Superpowers plans and specs](../superpowers/README.md) | Plans and design specs from the spring 2026 planning workflow, including the original licensing design spec, with `archived/` subfolders for finished work. |
| [Archive](../archive/README.md) | Finished release plans, past audits and redesign records, with their own index. |
| [Reviews](../reviews/README.md) | Dated audits: the pre-v1.0 code review, the test-suite audit, prompt audits, the licence review and the latest docs audit. |
| [Backlog triage, 2026-08-06](../triage/2026-08-06/README.md) | A one-day triage of every open issue, with briefs for the questions that needed a decision. |
| [Spikes](../spikes/README.md) | Probes, spikes and research notes. Code and tests cite these as evidence, so they stay where they are. |
| [Design history](../design-history/README.md) | The record of the removed logo and banner explorations, and design-session chat transcripts from the "calm" interface iterations. |
| [Roadmap history](../roadmap-history.md) | The roadmap as it stood on 2026-09-28, frozen when the live roadmap was cut down to what is ahead. |
| [v1.0 triage](../v10-triage.md) | The May 2026 row-by-row v1.0 scope marks; the decision record behind the roadmap's wave list. |

Records that sit beside live docs rather than in these folders, such as the design-system phase
plans, are listed in the [Contributing map](contributing.md#design-system) and say "historical" at
the top.
